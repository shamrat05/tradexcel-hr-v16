## Design and native mechanism

Frappe v16 Desk defines `--card-bg`, `--text-color`, and `--border-color` in its light/dark theme sources. The installed Desk imports Bootstrap 4.6.2. Its Bootstrap tables do not consume Bootstrap 5's `--bs-table-*` variables; Frappe's own Desk `.table` rule already uses `color: var(--text-color)`. The PR's card rules correctly fix the surface mismatch, so this review removed the inert table overrides and retained only the page-scoped card rules. The Live Locations table remains inside its themed card and inherits Frappe's native table text theme.

No custom theme system or global card/table selector was added. The regression verifies both actual page roots, the Live Locations table/card nesting, and the Frappe tokens.
