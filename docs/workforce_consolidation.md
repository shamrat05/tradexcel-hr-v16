## Stable boundary and unresolved evidence

The base must install with Frappe, ERPNext, HRMS and this application without the
legacy package, a customer backup, or statutory feature imports. Company data,
jurisdiction, salary structures and policy decisions remain native configuration.

primary action. Earlier independent PR 74 review reproduced this on the preceding
base too. Grouping alone does not resolve it. Read-only HR device actions may
still reach a native permission denial; no permissions are broadened to hide it.

Entry destination. These limitations are not replaced with core patches or
unverified claims of a fully error-free UI.

Local source, isolated integration, deployed preview, remote CI and physical
staff/device acceptance are separate categories. Physical devices, independent
legal/translation review, real staff UAT and production authorization are pending.
