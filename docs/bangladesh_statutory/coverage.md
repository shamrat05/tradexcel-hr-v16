## Field authority and protected schema

`statutory_form_specs.json` owns the required field-key set, section identity, required-value flags and historical source hash. The editor can change presentation labels, translations, weights and approved earning-component mappings, but cannot delete/invent keys, disable required values or override native money/hours/leave balances through evidence. User expressions are never evaluated.

## Generation and evidence boundaries

Preview and downloads enforce native DocPerm, explicit Company scope, permitted Employee lists and Branch/Department filters. Supplemental values use only submitted, independently reviewed evidence effective at the reporting end. Public/unreadable attachments are denied. Manual establishment returns are denied for incompatible narrowed user scopes.

PDF and DOCX use the same read-only context. Downloads are CSRF-protected POST requests and write an immutable actor/template/hash/scope/source-reference audit with status `Draft Generated`. Draft, reviewed evidence, generated file, legal approval, filing and payment remain separate. No filing acknowledgement or statutory approval is invented.
